# Galaxy80 网页控制台

在项目目录运行 `npm start`，用桌面 Chrome 或 Edge 打开 http://127.0.0.1:8080。
保持原驱动关闭，点击“连接键盘”，选择有线 Galaxy80 或无线 Galaxy80-2.4g。
修改自动应用，不需要再次保存。

## 2.4G 使用说明

- 支持按键和 Fn 层映射、板载灯效、逐键配色、宏、响应档位、休眠及三个快捷键禁用选项。
- 无线设置通过接收器发送，并检查键盘回复；这不等同于完整配置读回。
- 无线连接使用最近有线备份和本浏览器已确认的修改。项目内附本次适配前读取的配置备份。若用原驱动或其他方式改过配置，请先接有线并读取一次，再切回无线。
- 配置记录保存在当前浏览器。更换浏览器前建议在“配置与备份”中导出配置。
- 键盘休眠时请按键唤醒。若页面提示通信中断，唤醒后点击断开、重新连接；未成功的修改仍会保留。
- 当前实时画面和音乐同步仅适配有线；无线可使用板载灯效。
- Alt 组合键禁用只检测左侧 Alt，此行为来自提供的固件。

`npm test` 运行协议与自动应用回归测试。固件文件仅用于协议分析和文件检查，网页不执行固件刷写。
